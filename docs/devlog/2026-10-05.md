## 오늘 한 개선과 이유

Claude 담당 일정 중 10-06 "KMVSS article numbers"가 내일 마감(3일 이내)이지만,
`regnav/sources/kmvss.py`를 다시 확인한 결과 어제와 동일하게 법제처 Open API 키(오너
전용 가입)와 일반 웹 접속(이 샌드박스에서 차단) 둘 다 없이는 자동차용 전자파(EMC) 조문을
채울 수 없다 — 여전히 막혀 있음만 재확인했다(로드맵에 확인 날짜 10-05 추가).

그래서 백로그 순위상 다음으로 완료되지 않은 항목인 4번 "Gradio 데모 디자인"(심사 기준
2: 완성된 제품 경험)을 진행했다. 이 항목은 "로딩 상태, 더 명확한 판정 카드, 짧은 사용법
패널, 비교표 링크, 모바일 레이아웃"을 요구하는데, 이 중 네트워크가 필요 없고 완전히
오프라인 테스트가 가능한 두 조각(로딩 상태, 사용법 패널)만 이번 실행 범위로 잘랐다.
판정 카드 디자인과 모바일 레이아웃은 실제 렌더링된 화면을 봐야 판단할 수 있는 작업이라
이번에는 손대지 않았다(다음 단계에 기록).

구현: (a) `regnav/i18n.py`에 `how_heading`/`how_body`(영/한) 키를 추가하고
`space_app.py`에 기본 접힌 `gr.Accordion`로 "How it works"/"사용 방법" 4단계 설명을
intro 아래에 배치(부품 입력 → 공식 원문에서 후보 검색 → Nemotron 판정 → 우선순위·출처
목록, 같은 주제가 여러 체계에 걸리면 비교표가 이어진다는 안내 포함). `switch_language`가
이 패널의 제목·본문도 함께 relabel하도록 반환값에 2개를 추가. (b) 리뷰 버튼에 로딩 상태를
추가: `go.click`/`part.submit`을 `start_review`(버튼 비활성화 + "Reviewing..."/"검토
중..."으로 교체) → `run_review`(변경 없음, `make_space.py` 부트 체크가 쓰는
`api_name="run_review"`는 그대로 유지) → `end_review`(버튼 복구)로 체이닝. 라이브
모드에서 최대 4개 동시 Nemotron 호출로 한 리뷰가 여러 초 걸릴 수 있어 Gradio의 일반적인
pending 오버레이보다 버튼 자체가 바뀌는 쪽이 더 눈에 띈다. `space_app.render()`(판정
표 자체)는 건드리지 않아 `scripts/fixtures/english_outputs_baseline.json`은 그대로다.
