## 구현

`space_app.render()`에서 경고 문구 다음, 첫 버킷 표 앞에 한 줄 요약을 추가했다: `**Summary:**
🔴 2 Must review · 🟠 7 Confirm · ⚪ 2 Reference only` (한글: `**요약:** 🔴 2 필수 검토 · 🟠 7
확인 필요 · ⚪ 2 참고`). 버킷 헤딩이 이미 쓰는 `order(lang)`/`_PRIO_ICON`을 그대로 재사용해
만들었으므로 새 로직 없이 항상 헤딩과 숫자가 일치한다. `regnav/i18n.py`에 새 키
`summary_heading`(EN "Summary" / KO "요약")만 추가했다. 이 백로그 항목의 범위("Gradio 데모의
디자인")에 맞춰 Gradio 데모(`space_app.render()`)에만 적용했고, CLI/API가 쓰는
`Report.markdown()`과 JSON, FastAPI 템플릿은 건드리지 않았다. 지난 다섯 번의 CSS 전용
슬라이스와 달리 `render()`의 실제 출력 내용이 늘어난 변경이라 `english_outputs_baseline.json`의
Gradio-render 다이제스트가 바뀌는 것이 예상된 결과였고(`markdown`/`json` 다이제스트는 불변),
`--update-english-baseline`으로 갱신했다. 사전 설치된 Chromium으로 직접 화면을 확인했다 —
pip로 설치한 Playwright 1.64가 기대하는 `headless_shell` 리비전이 사전 설치본과 달라
`chromium.launch()`가 바로는 실패했으나, `executable_path`를 사전 설치된
`chromium-1194/chrome-linux/chrome`로 지정하니 정상 동작했다. 1280px 영어와 390px 한글
화면 모두 요약 줄이 기존 버킷 헤딩과 같은 색 점 아이콘으로 깔끔하게 렌더링되고, 콘솔 오류
없음, 모바일에서 페이지 전체 가로 스크롤도 없음을 확인했다. 의도적으로 "진짜 독립 블록
카드" 리라이트(표 모양을 검증하는 기존 테스트들을 다시 써야 하는 더 크고 위험한 변경)는
건드리지 않고, 그보다 작고 안전한 다음 조각만 처리했다.
