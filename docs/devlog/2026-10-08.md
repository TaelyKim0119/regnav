일정표(Dated schedule)에서 Claude 담당이면서 오늘(10-08) 기준 지났거나 3일 이내인 항목은
10-06 "KMVSS article numbers"뿐이다 — `regnav/sources/kmvss.py`를 다시 확인했지만 법제처
Open API 키(오너 전용 가입)와 일반 웹 접속(이 샌드박스 차단) 둘 다 여전히 없어 자동차 EMC
조문을 채울 수 없고, 이미 10-03/05/06/07에 네 번 같은 결론을 기록했다. 다섯 번째로 "막혀
있음"만 반복하는 것은 가치가 없다고 판단해 로드맵 업데이트 없이 백로그 순위로 넘어갔다.

백로그 1·1a·2·3번은 전부 "done"(남은 항목은 오너 전용이거나 의도적 보류), 4번(Gradio 디자인)
남은 작업(판정 카드)은 10-06/07 두 번의 실행에서 이미 스크린샷으로 확인 후 "읽을 만함, 급하지
않음"으로 미뤄둔 상태였다. 그래서 **6번 "FEEDBACK.md"**(Most Valuable Feedback 상 대상, 전혀
손대지 않은 상태)를 골랐다. 일정표상 마감은 10-17이라 아직 3일 이내는 아니지만, (a) 완전히
손대지 않은 항목이고 (b) 코드를 전혀 건드리지 않는 순수 문서 작업이라 이번 실행 범위(약 1시간)

## 구현

`docs/submission/FEEDBACK.md` 신규 작성(영어, Devpost 제출용 — 다른 `docs/submission/*.md`와
동일 언어). 로드맵 백로그 6번에 이미 적혀 있던 다섯 가지 마찰 포인트를 각각 저장소의 실제 코드/
커밋 증거로 재구성했다(기억이 아니라 코드를 다시 읽어 인용):
- 모델 ID를 찾기 어려움 -> `scripts/list_models.py`로 직접 `models.list()`를 호출해 찾은 과정.
- reasoning 토큰이 `max_tokens`를 깎아먹음 -> `regnav/judge.py:52-55`의 주석과
  `docs/submission/DEVPOST_STORY.md`에 남아있던 이전 값(300 토큰)을 대조해 "300 -> 11개 중
  5개 빈 JSON -> 1000으로 올려 해결"이라는 전/후 숫자를 그대로 인용.
- Token Factory에 지출 한도가 없어 자체 가드를 만든 과정 -> `regnav/budget.py`(리뷰당/일별
  호출·토큰 한도, 퍼블릭 데모 전용 더 낮은 상한).
- 프로모 코드가 일반 Top up 다이얼로그에서 통과하지 않고 별도 폼이 필요했던 점.
- Tavily가 unece.org의 정확한 PDF는 찾아내지만(`pdf_links()`) 추출은 실패하는 점
  (`regnav/sources/tavily_search.py`의 docstring에 남아있는 2026-09-29/09-30 실측 기록을
  그대로 인용) -> EU 관보(OJ) SPARQL/CELLAR로 대체한 이유.
- 실패한 Scope 추출을 "아직 안 해봄"과 구분하지 못해 반복 검색이 발생했던 점 ->
  `_un_lookup()`의 negative cache로 해결한 과정.
추가로 두 가지를 보강했다: 첫 라이브 실행에서 Nemotron 판정 품질이 실제로 좋았다는 점(키워드
랭커의 오류를 scope 인용으로 정정, `DEVPOST.md`의 "What we learned" 절과 동일한 사례를
재인용)과, JSON 모드가 가끔 거부되어 `_ask()`가 평문 폴백을 쓰는 점. 마지막으로 무료 HF
Space는 ZeroGPU만 가능하고 `@spaces.GPU` 함수 등록이 필수라는 점(스폰서 제품은 아니지만 이
해커톤에서 무료 HF Space를 쓰는 모든 참가자가 겪을 문제)도 별도 항목으로 적었다. 문서 끝에
Devpost 폼에 그대로 붙여 넣을 수 있는 짧은 버전(short form)도 추가했다.

`docs/submission/DEVPOST.md`의 `## Feedback for Nebius / NVIDIA` 자리표시자와 "Devpost answer
text (Nemotron rating 9)"는 건드리지 않았다 — 로드맵 10-17 일정 항목에 속하고, 특히 "rating
9"는 오너 본인의 주관적 평가라 Claude가 추정해서 채울 수 없는 값이기 때문이다.
