## 오늘 한 개선과 이유

일정표의 Claude 소관 항목 중 10-17 FEEDBACK.md/Devpost 답변 행은 이미 10-08/10-09에 글을 다
썼고 남은 건 오너 본인의 "Nemotron rating" 숫자뿐이라 오늘 할 일이 없었고, 3일 이내 기한인
다른 Claude 소관 항목도 없었다. 그래서 백로그 순위대로 점검: 1·1a·3번은 실 Tavily 키 검증이나
held-out 전용 임계값 조정 금지(하드룰)로 막혀 있었고, 7번(KMVSS)은 법제처 API 키 없이는
불가였다. 4번(Gradio 디자인)의 남은 조각("진짜 독립 블록 카드" 리라이트)은 표 모양을 검증하는
여러 테스트(`check_korean_scope_display`의 `line.count("|") == 4` 등)를 전부 다시 써야 하는
크고 위험한 변경이라, 오늘 하루 치 작업으로 끝내고 검증하기엔 무리라고 판단해 보류했다.

대신 백로그 2번 본문을 다시 읽다가 적힌 내용이 틀렸다는 것을 발견했다: "FMVSS and KMVSS have
no equivalent 'outside the catalogue' path yet"라고 써 있었지만, `regnav/pipeline.py`의
`review()`를 직접 읽어보니 `tavily_search.mentioned_regulations()`가 뽑아내는 FMVSS 번호(`fm`
세트)를 전체 eCFR 인덱스에서 번호로 찾아 후보에 추가하는 코드(211-214행)가 이미 **최초
커밋(`a4c5a57`, 09-24)부터** 있었다. 다만 이 경로는 `tavily_search.search()`가 실제
`TAVILY_API_KEY`가 있어야만 결과를 반환하고 자동화 실행은 항상 키를 비워두기 때문에, UN
쪽과 달리(`check_uncatalogued_un_candidate`, 10-02에 추가) 오프라인 테스트가 한 번도 이
경로를 실행한 적이 없었다 — 즉 "안 만든 기능"이 아니라 "만들어졌지만 CI가 한 번도 돌려보지
않은 코드"였다. 코드가 깨져도 잡아낼 방법이 없는 상태라, 오늘의 개선으로 이 틈을 메우기로
했다. 정확도나 동작을 바꾸는 변경이 아니라 순수 회귀 테스트 추가라서 하드룰(held-out
임계값 조정 금지, 제로 지출)과도 충돌이 없고, 60분 안에 안전하게 끝낼 수 있는 범위였다.

## 구현

`scripts/test_dryrun.py`에 `check_fmvss_mentioned_candidate`를 추가했다(`check_uncatalogued_un_candidate`와
같은 방식: `tavily_search.search`를 스텁으로 교체). 테스트 파트 문구("Aftermarket infotainment
touchscreen head unit")는 `pipeline.fmvss_candidates()`의 키워드 매칭으로는 FMVSS 108("Lamps,
reflective devices...")을 전혀 찾지 못하도록 고른 것이고, 웹 검색 스니펫에만 "FMVSS 108"이라는
번호가 등장한다고 가정했다. `pipeline.judge`를 스파이로 감싸 실제로 판정기에 전달된 scope
텍스트를 가로채서, 그게 제목 반복이나 Tavily 스니펫이 아니라 커밋된 eCFR 스냅샷의 진짜 S1
Scope 발췌문(`ecfr.scope("571.108")`)과 정확히 일치하는지 확인했다 — UN의 "catalogue 밖" 경로는
공식 scope 텍스트가 아예 없어 Tavily 스니펫만으로 판정하는 반면, FMVSS는 이미 커밋된 스냅샷에
진짜 조문이 있으므로 이 경로가 오히려 더 강한 근거를 판정기에 준다는 점도 확인 대상에 넣었다.
`docs/ROADMAP.md` 백로그 2번에 이 정정 내용을 기록하고, KMVSS만 여전히 "catalogue 밖" 경로가
없다는 점(검색 대상이 작은 큐레이션 주제 목록뿐이고 번호로 찾아볼 인덱스 자체가 없음 — 7번
항목과 같은 법제처 API 키 문제로 막힘)도 명확히 했다. 코드 로직은 전혀 건드리지 않았다
(`regnav/pipeline.py`, `regnav/judge.py`, `regnav/sources/*.py` 무변경).
